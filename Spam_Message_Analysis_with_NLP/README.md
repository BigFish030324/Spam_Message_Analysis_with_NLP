# Natural Language Processing & Spam Message Classification

A comprehensive Python-based Natural Language Processing (NLP) project exploring fundamental text preprocessing and language analysis techniques (Part A) and developing supervised machine learning models to classify messages as spam or ham (Part B).

---

## System Architecture

The project combines fundamental NLP techniques with data-driven machine learning approaches to analyse natural language and automate spam message detection.

- **Language:** Python
- **Domain:** Natural Language Processing (NLP), Machine Learning
- **NLP Techniques:** Word Tokenisation, Stop Words and Punctuation Removal, Word Stemming, Part-of-Speech (POS) Tagging, Parse Tree Analysis
- **Machine Learning Task:** Supervised Binary Text Classification
- **Model Development:** Model Selection, Hyperparameter Optimisation, Ensemble Modelling
- **Model Evaluation:** Classification Performance Metrics and Comparative Analysis

---

## Core Modules

### Part A: NLP Preprocessing & Language Analysis

- **Tokenisation & Text Filtering:** Implements word tokenisation and removes stop words and punctuation to prepare textual data for further processing.
- **Word Stemming:** Explores and compares different stemming algorithms to reduce words to their stem forms and examine their effectiveness in text normalisation.
- **POS Tagging & Parse Tree Analysis:** Applies Part-of-Speech tagging to identify grammatical categories and analyses parse trees to examine the syntactic structure of sentences.
- **Sentence Probability Analysis:** Calculates sentence probabilities using unsmoothed and smoothed bigram language models, examining the effects of smoothing on probability estimation.
- **Comparative Tokenisation Approaches:** Investigates alternative tokenisation methods using Moses Tokeniser, TextBlob, Gensim, and spaCy to compare different NLP libraries and their text processing approaches.

### Part B: Supervised Spam Message Classification

- **Dataset Selection & Exploratory Data Analysis:** Acquires and examines the dataset to understand its characteristics, class distribution, and relevant patterns before model development.
- **Data Preprocessing & Feature Preparation:** Processes message text and prepares the dataset for supervised machine learning classification.
- **Machine Learning Model Development:** Implements supervised learning models to distinguish spam messages from legitimate messages (ham).
- **Hyperparameter Optimisation:** Investigates model hyperparameters and applies optimisation techniques to identify suitable configurations and improve classification performance.
- **Model Evaluation & Comparative Analysis:** Evaluates and compares model performance using appropriate classification metrics, supported by results presentation and critical discussion.
- **Ensemble Modelling:** Explores an ensemble model to combine multiple model predictions for spam message classification.
